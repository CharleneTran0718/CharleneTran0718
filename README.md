My experience includes testing frameworks and using automation tools to improve efficiency, identify defects early, and enhance overall product reliability throughout the development lifecycle. I’ve gained proficiency in languages such as Python, Java, C#, JavaScript, TypeScript, SQL, and Node.js, along with experience working with NoSQL databases such as MongoDB and Supabase.

Alongside testing, I bring development experience on both the front end and back end. I enjoy building projects on the side to continuously sharpen my skills and explore new technologies. I’ve built responsive, user-focused applications using React, React Native, and Next.js, and have designed and optimized APIs and improved database performance using Python, Java, and Node.js. I also have experience deploying and scaling applications on cloud platforms like AWS and Azure, and collaborating through Git and GitHub.

Beyond coding, I've also expanded my knowledge on virtual machines, networking fundamentals, and systems administration tools such as Active Directory and VMware. I’ve used platforms like Jira, SharePoint, and TeamDynamix for project management, tracking, and documentation in team environments.
